# v4 supervisor and analytic-reference checker

`supervise_campaign.py` is the v4 supervisor snapshot; its only change from v3 is leaving declared output parent directories absent for the program to create.

`qualification_checks_control.py TASK_DIR OUTPUT_JSON` is a data-only adapter over the frozen six-job checker at `tools/qualification_checks.py`. It keeps the six original native/profile checks, full-grid and 179-node validation, finite-value and q·P/(2E) gates, and descriptive cross-code summary. It adds the seventh `dsv4-analytic-control-l3` dataset, requires both completed receiver-gate jobs before that job, and verifies the exact original state snapshot. All 10 profile04 job IDs must be unique and exactly match the reviewed set; each must have completed with return code zero, unchanged inputs, verified cleanup, matching log hash, exact declared output set, and output hashes matching supervisor state. It binds the state, job logs, declared outputs, checker/adapter source, YSpec baseline trace and radial-sampling references, and optional radial-node files before and after assessment. An optional YSpec `radial_nodes.csv` must equal the shared state-bound sampling input; if absent, its absence is also tracked. The control is compared with both v6 native and profiled kernels, trace/spectrum tables, physical options, domain fields, radial nodes, and energy fields at the existing per-channel/per-column 2e-13 limit. Original v4-v6 results are retained with per-channel/column error scales and locations; old-v4 versus analytic-control metrics provide a third mechanism diagnostic. If original parity fails while control passes, the report status is `PASS_WITH_ANALYTIC_REFERENCE_CONTROL`, and `original_parity_passed` remains false even if the control also fails. A control mismatch or evidence mutation fails the report. The adapter launches no scientific executable and refuses to overwrite its JSON output.

Synthetic data-only tests verified that a historical channel mismatch remains reported with its error location while a matching control produces the controlled status, and that changing the control data beyond tolerance fails qualification. No scientific output or source was changed.
