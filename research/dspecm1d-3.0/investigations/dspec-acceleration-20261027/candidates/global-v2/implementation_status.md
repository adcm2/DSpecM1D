## Change log

- Candidate created from the approved frozen source tree. Prior evidence and other candidates remain untouched. No build or physical run has been performed by this implementation agent.
- Created as a fresh copy of `candidates/global` after the saved fresh-review HOLD. All remediation edits are confined to `candidates/global-v2`; the original candidate and review remain preserved.
- Added the missing sorted-label coefficient lookup and fluid projection to the global transform path. The path uses the prototype-compatible `GSHTrans::TransformKernel::Loop` plus FFT longitude synthesis; it does not claim Eigen GEMM for angular synthesis. Same-spin channels are batched at L<=32; high-degree transforms stay single-channel to bound temporary arrays.
- Local m-prime coefficients are now looked up once per degree/channel and reused across all global m during frame rotation, avoiding repeated label searches in the inner order loop.
- Hardened spool writer/reader: exact DC-inclusive audit identity `frequencyBin == spool index`, duplicate/missing audit rejection, finite z/q/residual and record data checks, checked header/count arithmetic before allocation, data-section/file bounds for all indexes and payloads, and non-overlapping record/L0 payload ranges. Reader validation uses a capped temporary interval table.
- Corrected worker memory accounting to include the full-side accumulator, 12 complex fields, frequency result, 12 coefficient arrays, two frame tables, one Generated-mode angular scratch estimate, low-L batch scratch, and a configurable per-worker transform scratch reserve. Reader index-validation scratch is separately capped and deducted before selecting up to 48 workers. Worker plans are initialized serially before parallel execution.
- Memory accounting now also includes each worker reader's retained side and frequency-audit metadata. The angular backend is identified in the manifest as GSHTrans Loop plus FFT longitude synthesis; it does not claim Eigen GEMM. Same-spin transform batches are used only at L<=32, with high-L transforms kept single-channel to limit transient arrays.
- Made worker creation exception-safe: if starting a later thread fails, signal stop, join all threads already launched, then rethrow; worker exceptions also join before propagation.

This follows the isolated global-GSH prototype's `SphericalGrid::InverseTransformation` path. It is source-only and has not been compiled or numerically validated.

Disk index tables are kept on disk; in-memory indexing is limited to per-key completion flags, side keys and frequency audits. A worst-case spool-size/free-space preflight and byte cap are enforced.

A first-64-angle prefix remains available for reference comparison; its manifest states that full transforms were performed. Working-memory preflight bounds independent side workers to 48, with Eigen internal threading fixed to one and FFT plans created serially.
- Added explicit native-side selection with an eight-side default cap, refusal when a larger spool lacks an explicit index list, and manifest mapping from output-side index to source element/node/radius/width/fluid metadata. The preflight counts required field/coefficient/accumulator buffers, reader metadata, rotation tables and one Generated-mode angular scratch table, plus a per-worker transform scratch reserve.
