Get started

Run your first seismogram

Run the PREM Bolivia displacement example with the settings used for the published DSpecM1D comparison, then inspect its samples and plot.

{{REVISION_NOTICE}}

Prepare the input

Build yspec as described in the installation guide. From the repository root, make a fresh run directory and copy the checked tutorial input and model into it. Inputs and outputs resolve relative to the JSON file, so the calculation writes only inside this directory.

mkdir -p build/first-seismogram
cp docs/site/examples/first-seismogram.json build/first-seismogram/input.json
cp examples/prem.200 build/first-seismogram/prem.200

Run the calculation

Use a deliberate thread limit. The input uses PREM with its ocean, full gravity, no attenuation, degrees 0–300, frequencies 1.5–21 mHz, a 300-minute record sampled every second, and a 1.9–20.1 mHz taper. The source is 647.1 km deep beneath Bolivia; the receiver is 3 km deep at the geocentric 80° latitude used by the comparison.

cd build/first-seismogram
OMP_NUM_THREADS=2 ../guide/bin/yspec input.json
ls first-seismogram.out.*

The program reports the model, degree/frequency ranges, sources, receivers and thread count on standard error, then writes the trace first-seismogram.out.1 and first-seismogram.out.receivers, a table giving, for each trace file, its source, the receiver's latitude, longitude and depth, and the epicentral distance, azimuth and back-azimuth.

Read the output

Each row contains four whitespace-separated values: time after the origin in seconds, then vertical (up), north and east displacement in metres. The trace has 18,001 samples from 0 to 18,000 seconds at one-second intervals. The saved receiver table gives its epicentral distance (about 99.79°).

Download the exact input fixture and the illustrative SVG plot, and read the plot provenance record. The image is rendered from the saved output. To reproduce it from the repository root after the calculation, run:

python3 docs/site/examples/plot_first_seismogram.py \
  build/first-seismogram/first-seismogram.out.1 \
  build/first-seismogram/first-seismogram.svg \
  build/first-seismogram/input.json

The documented parameters match the published DSpecM1D setup, but the waveform is not yet certified as converged: across the three components, maximum sample differences between the 300- and 600-minute runs are 1.43–2.19% of each component’s 300-minute peak; relative L2 differences are 2.35–3.60% of each component’s 300-minute L2 norm. Halving the sample step and tightening the local solver tolerance separately changed the tested waveform by less than 0.1%; these checks do not resolve the duration dependence. Treat the figure as a reproducible comparison setup with an explicit unresolved record-length limit, not as a validated reference solution.
