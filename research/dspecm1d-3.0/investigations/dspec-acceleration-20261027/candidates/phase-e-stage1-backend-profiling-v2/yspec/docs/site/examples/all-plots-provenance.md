# Plot output status and provenance

This record tracks all 21 distinct YSpecpp documentation plot outputs: four tracked site assets and 17 figures generated by the README example scripts. The plotting corrections are implemented, but a successful render only verifies the renderer and saved data path. It does not establish numerical convergence or validate a phase interpretation. No figure is certified as scientifically converged by this campaign.

The current-source first-seismogram inputs, measured numerical comparisons, and raw-output hashes are recorded in [first-seismogram-provenance.md](first-seismogram-provenance.md) and [first-seismogram-evidence.json](first-seismogram-evidence.json). The per-output machine-readable hashes and render status are in [all-plots-provenance.json](all-plots-provenance.json). Its 300-to-600 minute duration check fails the declared 1% gate; the maximum sample difference is 1.43–2.19% of each 300-minute component peak, and relative L2 difference is 2.35–3.60% of each component’s 300-minute L2 norm. The 0.5-second/tighter-tolerance joint check passed the stated local waveform tolerance, but this does not repair the duration limit.

The machine-readable manifest records output hashes and rendering environments for all completed figures. Spatial panel labels now say `slice max`; this is the evaluated slice maximum before display clipping. Raw results remain in machine-local evidence directories and are not checked into the repository. Example output names below are relative to their example directory.

The Phase 1 audit inventory is an external handoff artifact; its findings were used to scope this record. The three PNGs produced by `docs/tools/check_examples.py` reuse the first and kernel fixtures above and are execution/format aliases, not additional demonstrations. Kernel windows named S, P or a diffracted phase target TauP arrivals but do not prove that the finite-frequency measurement isolates that ray. The shallow 5 km force example remains a purpose-specific exception and has no accepted convergence result.

When a plot changes, rebuild it from the matching saved numerical output, record the canonical input/model/renderer hashes and rendered-output hash in the JSON manifest, then rebuild the site and run `python3 docs/tools/check_docs.py build/plot-corrections-docs/site`. The checker verifies all 21 current fixture and source hashes and compares the four tracked image hashes with both the repository files and built copies. It does not assess numerical convergence, phase isolation or scientific validity; those claims require the separately recorded saved-result evidence above. Machine-local raw-output paths are optional evidence and are intentionally not required by CI.
