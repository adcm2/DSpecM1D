Important boundaries identified in the source:

- CMake's default source build uses FFTW, builds the three C++ programs, enables OpenMP, enables NetCDF model-file output and enables tests/examples for a top-level checkout. `YSPEC_PYTHON` defaults off. The Python package instead selects pocketfft and turns NetCDF, standalone programs, examples and C++ tests off.
- The Python package requires Python 3.12 or later and NumPy. Its `plot` extra declares Matplotlib and `planetmodel[plot,maps,netcdf]`; `obspy` and `test` are separate extras.
- Program JSON fields use their named input units: depth and grid spacing with `_km` are km, coordinates/distances/angles with `_deg` are degrees, frequency bands/tapers with `_mHz` are mHz, and times with `_s` are seconds (`length_min` is minutes). The Python convenience API uses km for depth/length, degrees for locations/angles, mHz for frequencies and seconds/minutes as named. The public C++ `YSpec` API uses SI dimensional values (including depth/radius in m, frequency band and taper in Hz, and source moment/force in N m/N), while geographic `Location` coordinates and great-circle angles remain in degrees and time remains in seconds. C++ traces are in SI units unless an instrument is attached; Python convenience inputs use km/mHz but returned numerical arrays are in SI units. Keep these interface contracts separate in the manual.
- Sampled 3D sections and maps are available without NetCDF. Only writing the through-earth volume as a `.nc` planetmodel model file requires a NetCDF-enabled C++ build. The Python package build has NetCDF disabled by default.
- `yspec-kernels` accepts one source and one receiver with one or more named cross-correlation traveltime measurements. Its JSON parser rejects unrecognized fields and applies CLI-specific requirements. Do not imply that all Python kernel workflows have the same CLI input restrictions.
- The selected main introduces `yspec-kernels`, Python calculation, plotting and sampled-kernel interfaces. The existing docs checker already requires the old API pages and exact symbol anchors; those checks and authored routes should be extended rather than replaced.
