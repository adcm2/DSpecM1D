YSpecpp · User guide

Synthetic seismograms, snapshots and kernels

YSpec solves the frequency-domain equations of motion in radius for spherically symmetric Earth models, then combines the spectra into traces, wavefield samples or adjoint sensitivity kernels.

Three calculation programs

All three programs read strict JSON, write their results beside the input file's chosen output prefix, and report progress on standard error. Set OMP_NUM_THREADS to bound the OpenMP workers.

Python interface and plotting

The source-built yspec-seismo package imports as yspec. It exposes models, calculation settings, sources and receivers, seismograms and strains, snapshots, traveltimes and radial or sampled kernels. The package adds the yspec-plot command; the standalone C++ programs come from the CMake build. Follow the Python guide for a pinned source install, or plotting guide for headless trace and kernel figures.

Models, physics and units

Models may contain isotropic or transversely isotropic solid and fluid layers with attenuation. Gravity can be omitted, treated with the Cowling approximation or included fully. Input JSON uses its named units: depth and grid spacing in km, geographic angles in degrees, frequency fields in mHz and time fields in seconds (record length in minutes). The high-level C++ API takes SI dimensional quantities; Python convenience inputs use km and mHz, while numerical result arrays are in SI units. See the input reference and output reference for each interface.

Seismograms use up, north and east components; snapshots use up, away and transverse, with away following the source great circle. The manual keeps calculated 3D sections/maps distinct from optional through-Earth NetCDF volume files.

Choose a route

Run the first seismogram, build a source-tree application with the C++ library example, or follow the installation guide. The generated API reference uses the public headers and README from the same source revision as this manual.

YSpecpp is a C++23 reimplementation of YSpec by David Al-Attar, following Friederich and Dalkolmo (1995) and Al-Attar and Woodhouse (2008). The repository is distributed under the BSD 3-Clause license.

Limits and evidence

The solver tolerance controls local integration steps; it is not a universal error bound on every trace. Check degree, frequency band, record duration and tolerance for the calculation of interest. The C++ source build provides a library target, but YSpec does not export an installed find_package(YSpec) package.
