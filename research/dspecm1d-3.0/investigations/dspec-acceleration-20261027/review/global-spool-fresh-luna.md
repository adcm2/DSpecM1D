# Fresh Luna review: global GSH and response spool

**Result: HOLD before build or science.** Static review only; no implementation edits, build, SSH, or numerical execution. Scope: `candidates/global/{global_gsh_tile.hpp,global_kernel_consumer.hpp,pole_response_spool.hpp}` against the accepted frozen `source-v2-frozen/physical_global_gsh.cpp`, current engine headers, and the recorded direct-evaluator pivot.

## Findings

- **Blocker — GSH header does not compile as written.** `GlobalGridPlan::evaluate` calls `coefficient(rec,fluid,mp,degree,component)` but `global_gsh_tile.hpp` has no declaration or definition for that helper. The response-owned copy contains the intended sorted-label lookup and fluid projection at `candidates/responses/global/global_gsh_tile.hpp:174`; synchronize the helper into the reviewed global candidate before any build. That helper should retain `rr + horizontalTrace` for fluid component 0 and zero the other nonradial components.
- **Blocker — spool offsets are not bounds-checked.** `PoleResponseSpoolReader` trusts header dimensions and both offset tables, then seeks and reads records without first validating the file size, table arithmetic, offset region, or each record's computed end. Truncation fails only when a read exhausts the stream; an in-file offset into metadata or another record can be accepted as data. Validate file length and overflow-safe table ranges at open, then require each record/L0 offset and payload end to lie in the data region and file.
- **Blocker — memory worker cap omits the side accumulator.** `fullSideAccumulatorBytes` is computed and reported, but `workersByMemory` divides the configured budget by `perWorkerBytes`, which excludes that accumulator. Add it to the per-worker estimate before deriving workers, and keep the manifest estimate consistent. FFT/GSH/Eigen/SEM/runtime internals are already appropriately disclosed as excluded, so this is a correctable known-array accounting gap.
- **Required spool audit hardening — enforce bin identity and domain bounds.** The writer requires two pole records and two L0 records for every bin-side key, and one finite nonnegative basis residual audit per bin; the consumer applies the `1e-12` residual gate. However, `setAudit` permits repeated/out-of-order `frequencyBin` values and does not require `audit.frequencyBin == bin`; the reader does not validate finite/ordered audits or require original bins to match the declared spool range. Enforce exact expected bin identity/count (including the intended DC/end-bin policy) before finalization or consumption. The response driver currently populates audit bin `k` for `k in [0,endBin)`, but the spool itself does not verify that contract.
- **Worker exception path — guard thread-launch failures.** Exceptions thrown inside workers are captured, all started workers are joined, and then the first exception is rethrown. If `std::thread` construction itself throws after earlier threads have started, stack unwinding destroys joinable threads and can terminate the process. Add a launch-failure join path. The configured maximum is 48 workers; with the main process and supervisor this is 50 campaign-owned threads.

## Static checks that passed

- Rotation convention matches the frozen prototype: the Wigner upper index is local `m'`, the lower index is global `m`; the coefficient is divided by `sqrt((2l+1)/(4π))` and multiplied by `exp(-i m longitude)`. The spin is passed to `GSHIndices`/inverse synthesis, not used as the Wigner upper index.
- The FFT-backed complete-2L point grid and band-L transform follow the prototype: `2L+1` Legendre nodes mapped by `acos(-x)`, `FastFFTSize(4L+1)` longitudes, declared base bandwidth `L`, and the same `InverseTransformation(L, spin, coefficients, Batch, field, Batch, Execution)` API call shape. Low-L node/weight parity is not rechecked in this module and remains a numerical gate.
- Source and unit-adjoint fields remain complex; the complex adjoint mixing factor is applied once to all six adjoint channels and separately to the two adjoint L0 terms. `pointKernel` consumes the result as `adjointDualStrain`, using the conjugated dual in its contraction. No extra double baseline or second `qMix` application was found in these three headers.
- Fluid projection and separate radial L0 handling are structurally correct once the missing helper is restored: the point-kernel path uses `rr + horizontalTrace` for fluid divergence; L0 records are added only to radial-radial and horizontal-trace channels.
- Output uses complete angular transforms for each frequency/native side, sums each frequency kernel into a full-side accumulator, and writes the selected angular prefix only after accumulation. The manifest labels a prefix as incomplete while stating that complete transforms were performed.
- Each worker gets its own reader, grid plan, and output stream; these contexts are constructed serially before `runOwnedTiles` starts. Requested workers are capped at 48 and Eigen is set to one internal thread. The prior O(tile-longitudes × L²) direct-per-point evaluator is recorded as rejected and is absent from this consumer path.
