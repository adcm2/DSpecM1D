# Parallel solver phase: parent design audit, 2026-10-27

Authorized: parallelise DSpec forward/adjoint solves; preserve evidence; nohup; max50 aggregate campaign threads. No figures/measurement change.

Independent degree slots in existing pole-frame route; l0 serial. Each worker executes source lift, independent matrix assembly, shared factor forward/unit-adjoint solves, and owns its output matrices. No worker calls shared visitor, sampling plan, spool writer or field sum. Results collected in original degree/family order. Existing SEM assembly/source/receiver implementations inspected on Tunya: shared SEM stores prebuilt bases and getters read them; source treatment constructs local matrices and quadratures; CMT accessors const. Legacy nonconst argument signatures alone do not imply mutation. Full-order angular ParamInfo path excluded from parallel scheduling.

Cache std::map, counters, caps, and reconstruction maximum protected by one mutex; compute callback runs unlocked, then signatures, entries and byte cap rechecked. No entry reference escapes lock; public result copies retained. Cache lifetime/moves require joined workers. Sparse solvers and chosen diagnostic backend are TLS; backend saved/restored per worker. Errors captured into distinct degree slots and rethrown after join, preventing exceptions crossing OpenMP. Profile TLS saved/restored including master scopes and merged after join. Eigen inner threading compile-disabled, OMP dynamic disabled; max48 solve workers plus supervisor/watchdog margin. Retained team hard-paused before a separate consumer worker pool.

Validation planned: old serial evidence comparison; serial vs 2/8/16/32 workers on physical DC+52-bin waveform/energy and native six-channel kernel; repeated high-degree run; no-cache direct weighted adjoint; spool byte comparison at small degree; bounded-cache fallback and exception checks. Thread/RSS receipts. Thread sanitizer if supported by runtime, otherwise explicit limitation.
