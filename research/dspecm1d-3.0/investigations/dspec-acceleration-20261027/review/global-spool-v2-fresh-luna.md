## Remaining blocker

- **Offset tables are range-checked but payload identity is not verified.** The reader now checks header arithmetic, file bounds, each payload length, and non-overlap across pole and L0 ranges. However, serialized pole payloads do not carry their bin, side, or source/unit-adjoint identity; L0 payloads carry no identity either. `validateAllOffsets` can therefore accept a valid permutation of distinct offsets in the index tables, and `read(bin, side)` will silently label the payload with the requested side/family and audit bin. Store and validate the payload key/family (or an equivalent per-slot identity/checksum bound to that key) so swapped index entries fail closed. Recheck this before proceeding.

## Remediations verified

- The missing coefficient helper is present. It uses `lower_bound` over `(m,l)` labels, checks the corresponding strain array with `.at()`, and applies the fluid projection (`rr + horizontalTrace` only for nonradial component 0). The writer and reader enforce strictly ordered unique labels, allowed local orders, and degree bounds, so the lookup precondition is met for spool-produced records.
- Rotation and mixing match the frozen prototype: the Wigner upper index is local `m'`, the lower index is global `m`; the `sqrt((2l+1)/(4π))` normalization and `exp(-i*m*longitude)` phase match; the frame angle comes from `axes[2]` with no extra source/receiver flip, as in the prototype. The complex mixing factor is applied once to each unit-adjoint channel and once to each separate adjoint L0 value. The result enters `pointKernel` as `adjointDualStrain`, whose contraction conjugates the dual field. Fluid projection is applied before rotation, with radial L0 kept separate.
- Grid and transform API match the accepted source: `2L+1` Gauss-Legendre nodes mapped by `acos(-x)`, `FastFFTSize(4L+1)` longitudes, base declared band `L`, `nMax=2`, Generated Wigner values and Loop kernel; `InverseTransformation(L, spin, coefficients, Batch, field, Batch, Execution)` matches the frozen batched call. Output batches are unpacked as contiguous channel-major fields; the consumer writes a flat theta-major prefix with six point-major kernel values, matching the documented prototype grid construction. Actual point/weight parity and polar convention remain runtime numerical gates; the frozen prototype itself marks polar conventions unvalidated.
- Writer closure requires one forward and one unit-adjoint pole record plus both L0 records for every bin-side key, and one audit for every bin. Audit identity is exactly `frequencyBin == spool index`, with duplicate/missing audits rejected and finite `z`, complex mixing and nonnegative finite reconstruction residual required. The consumer applies the existing `1e-12` residual gate. Kernel driver modes require DC inclusion; the writer and reader enforce the contiguous DC-inclusive bin range, so there is no shifted-first-bin format ambiguity.
- Reader header/count arithmetic is checked before allocation, native-side and audit tables are finite and bounded, and index/payload ranges are checked against file length with a 256 MiB cap on the interval validation table. Payloads cannot overlap or alias.
- The consumer's per-worker estimate includes the full-side accumulator, twelve complex fields, frequency-result buffer, twelve coefficient arrays, two frame Wigner tables, one Generated-mode angular scratch estimate, low-degree batch scratch, retained side/audit metadata, and the configured transform reserve (default 2 GiB per worker). The offset-validation table is separately capped at 256 MiB and deducted before worker selection. It does not claim to retain Generated scratch for all theta rows. FFT longitude synthesis with the GSHTrans Loop backend is stated explicitly; no Eigen GEMM claim is made for angular synthesis.
- Worker count is capped at 48, Eigen threading is set to one, each worker owns a separate reader/grid plan/output stream, and contexts are constructed serially before workers launch. If thread creation fails partway through startup, the stop flag is set, every launched worker is joined, and then the launch exception is rethrown. Worker exceptions are likewise rethrown only after joins.
