source-lift application and L0/T0/material/force normalizations. Array payload is

metadata and hashes, not reconstructed decimal coordinates. Missing |m|>l slots
are zero. Source|m|<=2,receiver|m|<=1. Merge spheroidalU/V and toroidalW at matching
degree/order/side exactly as existing coefficient capture; l0 is separate U only.

Export AFTER existing source-moment and receiver-unit-basis projection so the
packet contains precisely the modes already used by accepted reconstruction.

source element, including its one-sided derivative. Do not add an adjoint lift
absent from the accepted path. Native derivative uses existing Dref/J branch,
canonical radius snap and element identity; no interpolation-policy/env changes.

2. Explicit normalization/formula map
Inspected DS radialToStrain and pinned YSpec StrainOf use the SAME displacement
convention u=U*Y*rhat+V*grad1Y-W*rhat×grad1Y. There is no extra blanket sqrt(l(l+1))
rescaling at this export point. The radial-slot map is identity:
YS(u,du,v,dv,w,dw)=DS(U,Uprime,V,Vprime,W,Wprime), with the SAME normalized radius.
For dimensional forward displacement U_SI=L0*U and derivative dU_SI/dr_SI=Uprime;
do not divide primes by L0 a second time. Adjoint payload remains a tagged
Hermitian-dual field, not mislabeled physical SI displacement.

For lambda=l(l+1),zeta=sqrt(lambda),eta=sqrt((l-1)(l+2)) for l>=2 else0:
  E_rr=Uprime; E_h=(2U-lambdaV)/r;

Multiply each by its X_lm^spin and exp(+im*phi); spin=(0,0,+1,-1,+2,-2).
Frame rotation stays accepted DS rotateStrain: c=a-i*b, multiply rplus byc,
rminus byconj(c),hplus byc^2,hminus byconj(c)^2. Source/receiver field frames
must not be interchanged. Degree0 has only rr/h; degree1 has no spin2 component.
No center samples occur in this case. Do not import a new center prescription.
