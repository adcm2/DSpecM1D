2. Intended implementation and exact dependency ordering

Retain original CLI/route as default degree-parallel baseline. Add an explicit
bounded frequency scheduling opt-in (e.g. DSPEC_FREQUENCY_WORKERS=1..8) with
result metadata distinguishing frequency_workers and solve_workers. Legacy
workers argument retains its current meaning unless opt-in is present; reject
frequency>1 combined with solve>1. New frequency1 route uses the same scheduler
logic as frequency8 with inner solves1, providing a scheduler serial control.
Do not reinterpret an8worker baseline invocation silently. Existing yspec route
remains untouched; new opt-in limited to dspec and dspec-forward controls.

Keep the two-pass algorithm, including the existing cache's unit-adjoint capture:
  A. Construct model/SEM/source/parameters/samplings on parent exactly once.
  B. Parallel35 complete initial-frequency tasks, each prepares its own workspace
     with solveThreads=1, captures forward+unit adjoints through the SAME stable
     BatchResponseCache, samples receiver, writes only components[k]/raw[k].
  C. Join every task, inspect error slots; only if all succeed perform unchanged
     serial measure()/FFT/window/normalization/adjoint-spectrum construction.
     No kernel task runs until the complete waveform and adjoint are available.
  D. Parallel35 complete kernel-frequency tasks, using already-populated response
     cache, task-local weights/workspace/points/fields, persistent private plans,
     original within-frequency section/order and first2bin validation behaviour.
     Each writes its own per-frequency section contribution buffers and metrics.
  E. Join, check errors/validation, then parent reduces contributions in strictly
     original increasing k order, for each original side/angle address. No worker
     ever adds into shared values. Serial I/O and integral audit follow unchanged.

Use OpenMP one outer region/pass and schedule(static); exactly8total numerical
workers maximum, solveThreads=1, Eigen and library pools1. Set Eigen/OpenMP global
settings before regions, never mutate process-global thread settings in workers.
Do not make thread-local root-per-frequency dumps to stderr. Preserve worker
backend selection by copying/restoring selected diagnostic backend in each worker,
as existing degree scheduler does; symbolic factor state is already thread_local.
Use one indexed result/error slot per frequency, not shared push_back. A local
workspace is destroyed by its owning worker before that worker handles next task.

For exact accumulation, contribution[k][section][side*angles+angle] is a plain
assignment of existing kernelVs result. Parent starts original values at+0.0 and
performs the original += in increasing k, retaining exact per-point arithmetic
sequence; no OpenMP reductions, pairwise sums or thread-order sums. Preserve
original material lookup/contraction expression/order, including fluid zeros.
35*293*(135+19)*8=12,634,160bytes (~12.05MiB) contribution storage is bounded and
small compared with existing~2.9GB response cache. Do not retain volume fields.
Use checked dimensions/overflow bounds for the allowed exact case and L3 audit.

Return no partial scientific success if a task fails. Catch each task's exception
into its indexed exception_ptr, allow already-dispatched work to complete, join,
then rethrow the lowest-frequency failure with pass/bin context on parent. Avoid
early-stop flags that unpredictably skip frequencies or alter successful-run work.
Parent alone emits deterministic progress/log messages after each joined pass;
small progress buffering is scheduler support, not numerical work removal.

3. Ownership/thread-safety audit and release requirements

Pinned remote call-tree audit is recorded in companion
stages12-stage2-thread-safety-audit-draft.txt, with full-file/function-span SHA256
and final receipt-binding supplement. Source and dependency binding in section7
supersedes its earlier pending/provisional notes. No shared lazy mutation found
on inspected selected routes. The exact frozen Stage1 profile.hpp/doc_driver.cpp
match the inspected versions; status/cache differences in the mutable draft are
excluded. Re-audit the final Stage2 delta before build, without re-opening scope.

Shared lifetime table:
  SEM: construct fully once, retain one stable address through both passes, no
    move/rebuild/reinitialization while tasks exist. Existing solver methods use
    read-only mesh/matrices and local return allocations on inspected routes,
    despite non-const signatures. Audit exact sourceTreatedRadial/Spheroidal/
    Toroidal, receiverElements, rvBaseFull/T, rvZR, sourceMatches/sourceElement,
    calculateForceRedCoefficients/T, hS/hTk/systemMatrix, interpolation and mesh
    getter call trees for lazy writes/statics. If any mutation exists, stop and
    surface the precise gap; do not clone SEM per task, change cache keys or add
    a broad mutex around full frequency work as an unmeasured fallback.
  SourceInfo/EarthquakeCMT,InputParameters,CommonModel,model,grid,source frame,
    nodes/samplings/receiver/direction: immutable shared inputs. Source methods
    inspected return computed scalars; receiver/projection methods allocate local
    vectors/matrices. YSpec Layer::operator() const reads polynomial coefficients
    and returns Material by value on inspected local source. Confirm pinned
    Segment lookup has no shared cursor and all workers avoid model/parser/FFT
    mutation. Existing shared-model operator calls remain in worker contraction.
  BatchResponseCache: keep original locked implementation and original entry/byte
    limits, single stable cache object shared by both passes. Every key uses the
    same &sem, family, degree, z and dispersion. getOrCompute holds mutex for
    signature validation/copies, unlocks for local compute, then locks admission;
    accessors/deriveWeightedAdjoint are locked. Do not change these semantics.
    Unique frequency/family/degree ownership prevents same-key concurrent misses.
    No clear(), move or destroy until joins. Stage2 must preserve miss/hit totals
    and stored response count/bytes; kernel nonradial pass must hit, not recompute.
  SamplingPlanCache: NOT thread safe. Its maps/counters/bytes and nested
    TensorAngularPlan basis maps are mutable; shared_ptr payloads make shallow
    copies unsafe. Create independent empty per-worker/per-section plans once,
    keep them for that worker's frequencies within kernel pass, and destroy after
    join. Do not clone pointer graphs from a warm shared plan. Cold builds repeat
    up to number of workers; disclose this unavoidable ownership cost explicitly,
    not as a cache-policy optimisation. Per-frequency fresh plans are forbidden
    because they discard the existing cross-frequency reuse unnecessarily.
  Workspace/PoleCoefficientCache/fields/points/records/coefficients/GSH Wigner:
    task-private; no sharing the mutable frequencyCoefficientCache_. Tensor
    local plan-owned Wigner and real/complex bases independent across workers.
    Audit pinned GSH/Interpolation internals for global lazy caches/static scratch;
    owned object alone does not establish thread safety. Do not add giant tables.
  Solver factors/backend: existing thread_local factors and backend. Serial
    degree iteration inside each frequency retains family order. Numerical
    factor/RHS counts unchanged; symbolic analysis/reuse counts can differ with
    new worker task history and must be reported rather than forced equal.
  Profiling: auditprofile stays disabled; mathprofile thread_local WorkerCapture
    and separate output slots, merge on parent after joins. Never share maps,
    active scope stacks or snapshots. Existing mergeWorker prefixes are for
    degree workers; avoid silently labeling frequency workers as degree workers.
  Results/I/O/FFTW helpers: indexed unique task slots; no shared stream/file writes
    or parent cumulative validation max/duration writes in workers. Per-task
    diagnostics reduced deterministically after join; serial measurement/FFTs.

Measured Stage1 full L200 invariants:14000nonradial response misses in initial pass and14000hits in kernel pass,
14000cache entries,70radial cache-bypass solves, hence14070numeric factorizations.
Forward/unit/weighted RHS-column counts must match Stage1 measured values exactly;
