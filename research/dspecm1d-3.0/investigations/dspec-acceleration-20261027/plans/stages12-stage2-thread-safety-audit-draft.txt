Findings and thread ownership
1. SEM private state holds mesh/material/base matrices assembled before tasks.
   SEMMatrices.h hS/hSa/pS/hSC/hSCa/pSC/hTk/hTa/pTk construct return-value sparse
   matrices from those stored matrices; even hS coeffRef modifies its local tmp,
   not shared base state. No mutation/lazy state in these getters.
2. SEMLG sourceElement/receiverElements and ltg methods use locals, const mesh
   and existing fluid/offset vectors. sourceMatches uses local scalar radius.
   Receiver selection returns a fresh vector. Preserve the same shared SEM
   address across passes because response keys bind &sem.
3. SEMSourceTreatment local element operators allocate local matrices, read
   mesh/material/scales and build force/lift results locally. Radial construction
   now runs concurrently across frequencies; its Wigner<double> is local.
   Spheroidal/toroidal reduced source coefficients create local result matrices
   and read const SourceInfo moment getters. No source object mutation found.
4. rvZR,rvBaseFull,rvBaseFullT allocate local node/receiver arrays and local
   LagrangeBasis. Non-const method signatures alone do not indicate writes:
   inspected definitions only read shared state and mutate returned/local data.
   SourceInfo const getters and moment conversions use scalar values or locals.
   Legacy InputParameters is from InputParser.h, not InputParametersNew.h;
   receivers() returns const reference and scalar getters are const.
5. RadialMesh getters use const vector reads. GLL() exposes a mutable reference,
   but frequency task paths inspect mesh through const SEM::mesh() and do not
   call GLL()/splitAtRadius(). Constructor-time mesh mutation stays before joins.
6. YSpec Layer::operator()(double) const selects a segment with upper_bound on
   const r_, then evaluates stored cubics into local Properties/Material. Segment
   has no mutable last-interval cursor/cache. Gravity uses local accumulators and
   const massBelow_/coefficients_. Model operator()(layer,r) delegates to this.
   Parsing and construction occur serially; no workers modify layers/scales.
7. Interpolation LagrangeBasis computes owned weights in construction, const
   Value/Slope/Evaluate read those weights and borrowed immutable nodes, with
   local denominators/sums. No static scratch or mutable lookup index. Lagrange
   interpolant similarly has const evaluation and local nearest-node scans.
8. GSH Wigner<double>: WignerRecursionReal<double> is double, so FillBlock takes
   if constexpr same_as<Work,Real>, directly calling ComputeBlock into this owned
   table's destination. The alternate float-widening branch has thread_local
   scratch; it is not instantiated for the double physical path and would still
   not be shared among threads. PreComputeTables allocates two per-call vectors,
   not global/lazy tables. Constructor owns offset_/data_ vectors; ComputeBlock
   writes only the passed view and uses local recursion values/read-only tables.
9. Wigner::ComputeAll queries OpenMP::InParallel and its omp parallel-for has
   if(!nested). Under the8frequency outer team it executes a serialized inner
   region, creates no additional active team, and each task owns its table.
   Outside an active outer region OMP_NUM_THREADS1 keeps the library serial.
   WignerMatrices uses the same guard and a vector scratch allocated per inner
   region worker, never global. ExceptionCapture is object-local with mutex plus
   atomic failed flag, rethrows after the inner region. Do not reuse its
   completion-order first exception as the outer scheduler's lowest-bin policy.
10. Existing BatchResponseCache entries/counters/limits/accessors are locked;
   miss computation is local outside lock; stable shared cache reused across
   passes. Own cache lifetime until both joins; no clear/move. Existing factors
   and selected backend are thread_local. Numeric factor/RHS/cache-entry counts
   must match Stage1; symbolic reuse history may change with worker assignment.
11. SamplingPlanCache and nested basis/Wigner shared_ptr payloads MUST remain
   independently owned by each persistent frequency-worker/section plan. No
   shallow plan copies or concurrent shared mutation. Workspaces own mutable
   PoleCoefficientCache; construct/destroy in one task. No shared field vectors,
   diagnostics maxima or result +=; parent reduces indexed contributions in k
   order. auditprofile stays disabled; mathprofile capture/merge is worker-local.
