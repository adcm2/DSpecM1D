2. Intended implementation and exact dependency ordering

Retain original CLI/route as default degree-parallel baseline. Add an explicit
bounded frequency scheduling opt-in (e.g. DSPEC_FREQUENCY_WORKERS=1..8) with
result metadata distinguishing frequency_workers and solve_workers. Legacy
workers argument retains its current meaning unless opt-in is present; reject
frequency>1 combined with solve>1. New frequency1 route uses the same scheduler
logic as frequency8 with inner solves1, providing a scheduler serial control.
Do not reinterpret an8worker baseline invocation silently. Existing yspec route
remains untouched; new opt-in limited to dspec and dspec-forward controls.

Keep the two-pass algorithm, including the existing cache's unit-adjoint capture:
  A. Construct model/SEM/source/parameters/samplings on parent exactly once.
  B. Parallel35 complete initial-frequency tasks, each prepares its own workspace
     with solveThreads=1, captures forward+unit adjoints through the SAME stable
     BatchResponseCache, samples receiver, writes only components[k]/raw[k].
  C. Join every task, inspect error slots; only if all succeed perform unchanged
     serial measure()/FFT/window/normalization/adjoint-spectrum construction.
     No kernel task runs until the complete waveform and adjoint are available.
  D. Parallel35 complete kernel-frequency tasks, using already-populated response
     cache, task-local weights/workspace/points/fields, persistent private plans,
     original within-frequency section/order and first2bin validation behaviour.
     Each writes its own per-frequency section contribution buffers and metrics.
  E. Join, check errors/validation, then parent reduces contributions in strictly
     original increasing k order, for each original side/angle address. No worker
     ever adds into shared values. Serial I/O and integral audit follow unchanged.

Use OpenMP one outer region/pass and schedule(static); exactly8total numerical
workers maximum, solveThreads=1, Eigen and library pools1. Set Eigen/OpenMP global
settings before regions, never mutate process-global thread settings in workers.
Do not make thread-local root-per-frequency dumps to stderr. Preserve worker
backend selection by copying/restoring selected diagnostic backend in each worker,
as existing degree scheduler does; symbolic factor state is already thread_local.
Use one indexed result/error slot per frequency, not shared push_back. A local
workspace is destroyed by its owning worker before that worker handles next task.

For exact accumulation, contribution[k][section][side*angles+angle] is a plain
assignment of existing kernelVs result. Parent starts original values at+0.0 and
performs the original += in increasing k, retaining exact per-point arithmetic
sequence; no OpenMP reductions, pairwise sums or thread-order sums. Preserve
original material lookup/contraction expression/order, including fluid zeros.
35*293*(135+19)*8=12,634,160bytes (~12.05MiB) contribution storage is bounded and
small compared with existing~2.9GB response cache. Do not retain volume fields.
Use checked dimensions/overflow bounds for the allowed exact case and L3 audit.

Return no partial scientific success if a task fails. Catch each task's exception
into its indexed exception_ptr, allow already-dispatched work to complete, join,
then rethrow the lowest-frequency failure with pass/bin context on parent. Avoid
early-stop flags that unpredictably skip frequencies or alter successful-run work.
Parent alone emits deterministic progress/log messages after each joined pass;
small progress buffering is scheduler support, not numerical work removal.
