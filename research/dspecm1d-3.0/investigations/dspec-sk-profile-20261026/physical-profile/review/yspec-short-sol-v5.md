# Short independent Sol check: frozen YSpec v5 streamed sampled kernels

26 October 2026. Read-only check of the frozen v5 source, the fresh Luna review, the saved L=3 native/profile runs and binary files, and the current high-degree waveform comparisons. I did not compile or run a solver.

**Decision:** the saved L=3 complete-grid adapter gate supports a conditional v5 path-equivalence pass. It does not establish a full high-degree kernel result or physical angular convergence. The v5 disk branch changes accumulation **storage order and I/O**, while keeping the per-point elastic contraction and SI/Love transform formula of the in-memory path. The parent-owned high-degree resource and convergence gates remain necessary.

## Formula and saved-output check

The kernel measurement reads the frozen SI baseline trace at 5 s spacing and sets `j_n = Hann(t_n) u_n` for the vertical receiver. Its reported energy is `E = (dt/2) sum_n Hann(t_n) u_n^2`, so the linear pairing against that **same frozen baseline** is `dt sum_n j_n u_n = 2E`. At L=3 the saved baseline is `E=1.2917153256316188e-11 m² s` and `2E=2.5834306512632377e-11 m² s`. `MakeAdjointSpectrum` multiplies the time sum by `dt`, applies the source/quantity unit scale, and uses one-sided frequency weights `df` at DC/Nyquist and `2df` at interior bins. This checks the intended SI objective/adjoint normalization in the source; the displayed `2E` is an identity of the **input baseline**, not an independent numerical test that YSpec's own forward waveform satisfies the same pairing at another degree.

In `SampledKernels.cpp`, each elastic product is still formed from the same forward `f`, adjoint `e`, and local material `m`, then assigned its real part to the eight-channel `local` block. V5 reads the matching scratch block, adds `local[(node*Elastic+q)*places+angle]` into file order `[(angle*nodes+node)*Elastic+q]` without changing values or frequency order, and writes it back. Final conversion divides the first five elastic channels by the same `modulus*length³`, calls `Transform(..., ParameterSet::Love)`, checks finite values, and writes A,C,F,L,N. I independently read the three saved binary files: v3 `[5][179][91]` transposed to v5 `[91][179][5]` is **elementwise exact**, and v5 native and instrumented files are elementwise exact. Each file has 81,445 finite doubles (71,617 nonzero) and 651,560 bytes. This is stronger than a small relative norm, but only for the L=3 case.

The L=3 input has all **179 native radial rows** (151 distinct radii, 28 duplicated-radius rows), including 54 fluid rows, crossed with `nTheta=7`, `nPhi=13` and 91 angles, for 16,289 sampled points. V5 keeps input row order, maps native interface endpoint `q=0` to `Side::Above` and `q=NN-1` to `Side::Below`, and makes the full degree-2L Gauss/longitude coordinate set directly. The L=3 parity verifies those choices end to end for this input. Full high-L radial/angle output, finite values, and disk/RSS bounds are still unmeasured here; the source preflight is an estimate, not a measured peak guarantee.

## Profile interpretation

The instrumented L=3 run has 53 saved scope entries. Summing their **exclusive** seconds gives `2.8190750290000004 s`, equal within floating rounding to the enclosing `physical_case_total` inclusive `2.819075029 s`; this is the correct closure check. The key `api.ComputeSampledKernels` occurs twice, once in the driver wrapper and once inside the implementation, so its saved `5.634605239 s` inclusive across two calls double-counts nested work and exceeds both the enclosing duration and process wall. It must not be presented as API elapsed time. The single driver wall timer reports numerical API `2.817308124 s`; scratch read/write, fsync, transform and output scopes are separately visible. This low-degree exact-byte/profile check does not establish a high-degree overhead bound.

## Angular refinement at the present ceiling

The saved YSpec L1792 versus L1536 windowed waveform has weighted relative L2 `1.2395486406241545e-3`, **above** the fixed `1e-3` gate, while energy relative difference is `7.949325260927067e-4`, below it. The conjunction therefore fails. L1827 was still running when this review was written, and there is no completed 1827 comparison to assess. A 1792→1827 comparison spans only 35 degrees; passing it alone cannot establish convergence when the preceding 1536→1792 jump fails. The cumulative degree response has previously oscillated, and a short terminal increment can be small through cancellation. Compare 1827 to both 1792 and 1536 and retain the windowed trace and energy metrics, but do not infer a rigorous omitted-degree tail from either pair. Under the current **field ceiling 1827**, there is no second substantial higher-degree reference to close the waveform gate. A defensible physical-convergence claim needs a justified tail bound or a reviewed extension of the numerical degree range, followed by an independent higher-L comparison; the protocol's fixed gate should remain unchanged. A close 35-degree step is useful diagnostic evidence, not a pass by itself.
