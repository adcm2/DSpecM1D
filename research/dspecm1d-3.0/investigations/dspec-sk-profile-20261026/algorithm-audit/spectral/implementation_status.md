# Spectral alternatives prototype status

This is a diagnostic-only prototype area for the advanced exact SK alternatives assigned in the audit. Production sources remain untouched. One compiler process and one numerical thread are the limits; timed runs will wait for the parallel implementation's benchmark window to finish.

## Scope and handoff

- Implement exact frequency-first cross-degree/order covariance contractions, including all same-frequency cross terms and the accepted strain-pair definitions.
- Measure verified full-rank/numerical-rank factorization alternatives including setup cost and storage; no arbitrary singular-value truncation is acceptable.
- Prototype scalar harmonic recoupling through degree `2L` and global-grid FFT only after frame conversion and convention checks against direct synthesis/quadrature.
- Consume actual solver-derived radial/angle coefficients from the parallel implementation when its packet is available. Synthetic checks are supplementary only.
- Preserve failed attempts and report exactness, tolerances, crossover, cold/warm cost, and memory.
