Reference

Parameter files

The parser consumes one value line per field in a fixed order. It skips blank lines and full-line comments beginning with #; it does not parse keyed name = value syntax.

Field order and meaning

#FieldUnits or accepted values
1Output prefixPath prefix; CLI appends _t.out for time series.
2Earth modelModel file path, commonly relative to data/ for bundled files.
3Mode type1 radial, 2 toroidal, 3 spheroidal, 4 all families; radial modes are removed when lmin > 0.
4Attenuation0 off, 1 on; the model must contain usable attenuation data.
5Gravitation selectorLegacy integer is parsed but currently does not choose solver physics. See the Cowling cutoff note below.
6Output type0 displacement (m), 1 velocity (m s−1), 2 acceleration (m s−2). Time is written in seconds.
7Potential/tilt correctionsLegacy integer is parsed but currently has no solver effect.
8Relative errorPositive dimensionless accuracy setting used by the multi-SEM path.
9–10lmin, lmaxInclusive integer angular-degree bounds; lmin ≥ 0, lmax ≥ lmin.
11–12fmin, fmaxFrequency limits in mHz; fmin < fmax.
13–14Duration, time stepDuration in minutes; sample interval in seconds. Both must be positive.
15–18f11, f12, f21, f22Filter corners in mHz; each pair is ordered low to high.
19–21Source depth, latitude, longitudeDepth in km; angles in degrees.
22–27Moment tensorMrr, Mrθ, Mrφ, Mθθ, Mθφ, Mφφ, in N m.
28Receiver depthDepth below the surface in km; nonnegative.
29Receiver countPositive integer.
30…Receiver locationsOne latitude/longitude pair per receiver, in degrees. Three columns per receiver follow the time column: radial, north, and east.
Optional finalCowling frequency cutoffPhysical frequency in mHz; omit or use zero to disable.

Gravity and Cowling behavior

The fifth legacy field is read by the parser but is not consulted by the current solver. Solver paths use self-gravity unless the optional final cutoff is supplied: spheroidal frequency bins below a positive cutoff use full self-gravity, and bins at or above it use the Cowling approximation. The cutoff is a physical frequency in mHz; zero or omission disables it. This selector is independent of the legacy gravity field.

Supplied first-run file

Annotated source file. Copy it before changing values; the parser validates field order and rejects extra trailing values. It intentionally uses attenuation off with the matching no-attenuation PREM model.
