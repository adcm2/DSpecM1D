Get started

Generate a first seismogram

Build the command-line tool, run the bundled single-receiver example, and plot its three displacement components.

1. Install prerequisites

On Ubuntu or Debian, install a C++23-capable compiler, CMake, Git, FFTW3 development files, and an OpenMP compiler runtime. GCC 13 or newer is a tested Linux toolchain for this build.

sudo apt update
sudo apt install build-essential cmake git libfftw3-dev python3-venv python3-pip

The project requires CMake 3.24 or newer and an OpenMP-capable C++23 compiler. CMake fetches the remaining dependencies from pinned revisions, so the first configure needs network access.

2. Clone and build

git clone https://github.com/adcm2/DSpecM1D.git
cd DSpecM1D
cmake -S . -B build/release -DDSPECM1D_BUILD_TOOLS=ON -DDSPECM1D_BUILD_TUTORIALS=ON
cmake --build build/release --target generate_seismogram first_seismogram --parallel 2

Use a fresh build directory if you change generators or build settings. The manual commands work with the CMake 3.24 minimum; the presets use schema version 6 and require CMake 3.25 or newer.

3. Run the example

OMP_NUM_THREADS=2 build/release/bin/generate_seismogram build/release/data/params/first_seismogram.txt

The CLI prints the output filename. The bundled single-receiver file writes build/release/output/first_seismogram.out_t.out. Its 152 time samples and modest degree/frequency band are an illustration of the workflow, not a convergence result. Attenuation is disabled in this example.

4. Plot the output

Install the small Python plotting dependencies in an isolated environment:

python3 -m venv .venv-plot
. .venv-plot/bin/activate
python -m pip install numpy matplotlib
python plotting/functions/first_seismogram.py build/release/output/first_seismogram.out_t.out --save build/release/output/first_seismogram.png --no-show

From a terminal with a display, omit --no-show to open the figure. The file has four semicolon-separated columns: time in seconds, then radial, north, and east displacement in metres for the single receiver.

Change the experiment

Copy data/params/first_seismogram.txt before editing it. The ordered fields control receiver coordinates and depth, source depth/location/moment tensor, output quantity, included mode families, frequency band, degree range, and attenuation. Start by changing the source or receiver coordinates, then vary lmax, mesh resolution, and the frequency band to check convergence. Enabling attenuation requires an Earth model with attenuation parameters. The optional final Cowling cutoff is documented in the parameter reference.
