Examples

Use the C++ library

The same tutorial source works in the repository build and as a standalone consumer of an installed package.

The calculation

The tutorial source is shared by the in-tree executable and standalone consumer. It reads the ordered parameter file, constructs the public input context, calculates and normalizes the spectrum, applies the standard filter, and writes the public time-series format to an explicit path.

#include <filesystem>
#include <iostream>
#include <stdexcept>
#include <string>
#include <DSpecM1D/src/FullSpec.h>
#include <DSpecM1D/src/InputParametersNew.h>
#include <DSpecM1D/src/OutputWriters.h>
#include <DSpecM1D/src/SignalFiltering.h>

int main(int argc, char **argv) {
  if (argc != 3) {
    std::cerr << "Usage: first_seismogram <parameter-file> <output-file>\n";
    return 1;
  }
  try {
    InputParametersNew params(argv[1]);
    SPARSESPEC::SparseFSpec solver;
    auto spectra = solver.spectra(params);
    spectra *= params.normFactor();
    DSpecM::FilterOptions filterOptions;
    const auto filtered =
        DSpecM::applyFilter(spectra, params.freqFull(), filterOptions);
    const std::filesystem::path output(argv[2]);
    if (!output.parent_path().empty())
      std::filesystem::create_directories(output.parent_path());
    DSpecM::writeTimeSeries(output.string(), params, filtered.timeSeries);
    std::cout << "Wrote time-domain seismogram to " << output.string() << '\n';
  } catch (const std::exception &error) {
    std::cerr << "first_seismogram failed: " << error.what() << '\n';
    return 2;
  }
}

The full source also reports command-line usage and catches solver and file errors.

Build and run in the source tree

cmake -S . -B build/release -DDSPECM1D_BUILD_TUTORIALS=ON
cmake --build build/release --target first_seismogram --parallel 2
OMP_NUM_THREADS=2 build/release/bin/first_seismogram \
  build/release/data/params/first_seismogram.txt \
  build/release/output/library_first_seismogram.out

The source is tutorials/first_seismogram.cpp. It accepts an explicit parameter-file path and output path, so it can be called from any working directory.

Install and build a downstream consumer

From the repository root, install the package to a local prefix. The consumer uses the same source file as the in-tree tutorial and links the exported target; CMake supplies the C++23 requirement through that target.

The standalone CMakeLists.txt is:

cmake_minimum_required(VERSION 3.24)
project(DSpecM1DFirstSeismogram LANGUAGES CXX)
find_package(DSpecM1D CONFIG REQUIRED)
add_executable(first_seismogram_consumer ../first_seismogram.cpp)
target_link_libraries(first_seismogram_consumer PRIVATE DSpecM1D::DSpecM1D)
cmake -S . -B build/release -DDSPECM1D_BUILD_TUTORIALS=ON
cmake --build build/release --target first_seismogram --parallel 2
cmake --install build/release --prefix "$PWD/build/release/install"
cmake -S tutorials/first_seismogram -B build/release/consumer \
  -DCMAKE_PREFIX_PATH="$PWD/build/release/install"
cmake --build build/release/consumer --parallel 2
OMP_NUM_THREADS=2 build/release/consumer/first_seismogram_consumer \
  "$PWD/build/release/data/params/first_seismogram.txt" \
  "$PWD/build/release/output/installed_first_seismogram.out"

A first downstream configure also fetches the same pinned dependency closure if it is not already available locally, so it needs network access. Compare the in-tree CLI, tutorial, and consumer outputs to confirm they use the same parameter values and workflow.

Numerical scope

The bundled input is intentionally small and fast. For a scientific result, test sensitivity to degree range, frequency range, and mesh resolution, then choose a model and physical options appropriate to the question. See the first-seismogram guide and parameter reference.
