Get started

Install and build

Supported first-run path: Linux with CMake, a C++23 compiler, FFTW3, and OpenMP.

Requirements

The project declares CMake 3.24 as its minimum. Build with a C++23 compiler and its OpenMP runtime; GCC 13.3 was used for the Linux tutorial checks. FFTW3 development files are required. Remaining C++ libraries are fetched from pinned revisions at configure time, which requires network access on a cold build. BLAS/LAPACK are not required by the updated GSHTrans dependency.

sudo apt update
sudo apt install build-essential cmake git libfftw3-dev python3-venv python3-pip

macOS is best-effort: install a C++23-capable compiler, CMake, FFTW, and a matching libomp runtime, then verify OpenMP is found during configure. Windows is not a verified build target.

Choose a build tree

Every build uses a separate directory and can be configured with command-line options:

# small user build
git clone https://github.com/adcm2/DSpecM1D.git
cd DSpecM1D
cmake -S . -B build/release -DCMAKE_BUILD_TYPE=Release -DDSPECM1D_BUILD_TOOLS=ON
cmake --build build/release --target generate_seismogram --parallel 2

# development build with tests, examples, and smoke checks
cmake -S . -B build/dev \
  -DDSPECM1D_BUILD_TESTS=ON -DDSPECM1D_BUILD_TUTORIALS=ON \
  -DDSPECM1D_BUILD_BENCHMARKS=ON -DDSPECM1D_BUILD_TOOLS=ON \
  -DDSPECM1D_ENABLE_SMOKE_TESTS=ON
cmake --build build/dev --parallel 2

Build parallelism above is capped at two jobs as a practical starting point. Pick a value suited to available memory and CPU. For manual solver runs, set OMP_NUM_THREADS=2 or another deliberate modest value; build parallelism and OpenMP runtime threads are separate controls.

Run the first calculation

Follow the first-seismogram guide for a complete CLI and plotting workflow. Use build/release for the documented user build and build/dev for development. Presets use schema version 6 and require CMake 3.25 or newer; manual configuration works with CMake 3.24.

Install the CMake package

Build and install to a local prefix:

cmake -S . -B build/release -DCMAKE_BUILD_TYPE=Release
cmake --build build/release --parallel 2
cmake --install build/release --prefix "$PWD/build/release/install"
cmake -S tutorials/first_seismogram -B build/release/consumer \
  -DCMAKE_PREFIX_PATH="$PWD/build/release/install"
cmake --build build/release/consumer --parallel 2

Consumer projects call find_package(DSpecM1D CONFIG REQUIRED) and link DSpecM1D::DSpecM1D. The imported target carries the C++23 compile feature and OpenMP dependency. On a cold configure, the package configuration fetches the pinned dependency closure, so network access may be needed. The complete consumer run command is in the C++ example.

Build the documentation

cmake -S . -B build/docs -DDSPECM1D_BUILD_DOCS=ON
cmake --build build/docs --target website

Doxygen is included in the API output when installed. The documentation build also copies the report asset used by the Love-number page.
